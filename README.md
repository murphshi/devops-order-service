# devops-order-service

## Overview
This repository contains the Order Service for the DevOps final project e-commerce platform.

## Responsibilities
- Provide REST API endpoints for order management
- Process order-related requests from the frontend
- Interact with the database for order storage

## Tech Stack
- Node.js
- Express

## Branching Strategy
This repository follows the Git Flow model:
- `main`: production-ready code
- `develop`: integration branch for ongoing development
- `feature/*`: new features
- `release/*`: release preparation
- `hotfix/*`: urgent production fixes
